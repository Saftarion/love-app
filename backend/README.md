# Love App — backend

Telegram-бот + API для связки пары, синхронизации таймера/колеса/мечт и push-приглашений на свидание.

## Установка

```bash
cd backend
npm install
cp .env.example .env
```

Впиши в `.env`:
- `BOT_TOKEN` — токен от @BotFather (**никогда не коммить .env в git**)
- `BOT_USERNAME` — юзернейм бота без @ (нужен, чтобы строить ссылку-приглашение `t.me/<username>?start=pair_XXXX`)
- `MINI_APP_URL` — заполнить, когда фронтенд будет захостен (используется в кнопке бота «Открыть приложение»)

## Запуск

```bash
npm run dev    # с автоперезапуском при изменениях
# или
npm start
```

Поднимет:
- Express API на `http://localhost:8787`
- Telegram-бота в режиме polling (не нужен публичный HTTPS/webhook для разработки)

## Как это работает

1. **Связка пары** — открыв Mini App, пользователь жмёт «Свяжите сердца» → `POST /api/invite/create` создаёт запись пары и возвращает ссылку `t.me/BOT?start=pair_XXXX`. Партнёр переходит по ссылке → бот ловит `/start pair_XXXX` → присоединяет её к паре.
2. **Синхронизация** — фронтенд шлёт `GET/PUT /api/state` с подписанной Telegram `initData` (HMAC-проверка в `src/initData.js`, как того требует Telegram). Данные (таймер, колесо, мечты) хранятся в `data/db.json` (lowdb, JSON-файл — этого достаточно для одной пары; для продакшена на много пар потребуется нормальная БД).
3. **Уведомления** — при добавлении мечты партнёр получает сообщение в Telegram. При вызове `/api/invite/date` бот шлёт партнёру приглашение с кнопками «Да» / «Не могу».

## Структура

```
src/
  index.js      — точка входа, поднимает бота и сервер
  bot.js        — обработка /start и ответов на приглашение
  server.js     — Express API
  db.js         — хранилище пар (lowdb)
  initData.js   — проверка подписи Telegram WebApp
```

## Известные ограничения (осознанно, для MVP на двоих)

- Синхронизация — поллинг раз в 7 сек, не WebSocket (проще, достаточно для двоих)
- БД — JSON-файл, не рассчитан на много одновременных пар
- Нет rate-limiting / защиты от спама приглашений — не нужно для приватного бота вдвоём
