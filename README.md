# Love App 💕

Telegram Mini App для пары — премиальный дизайн в стиле Apple.

## Экраны
- **Таймер** — счётчик дней/часов/минут вместе + цитата дня о любви. Настройки: дата, название, тема (тёмная/светлая, у каждого своя).
- **Колесо** — рандомный выбор активности с анимацией. Редактируемые варианты + 4 цветовые палитры (Закат/Океан/Пастель/Неон).
- **Мечты** — список целей: добавить, отметить, переименовать, удалить.
- **Свидание** — позвать партнёра, приглашение приходит push-сообщением в её Telegram.
- **Связка пары** — при первом запуске в Telegram: ссылка-приглашение, партнёр переходит по ней и всё становится общим.

## Запуск фронтенда
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # прод-сборка в dist/
```

Вне Telegram (обычный браузер) приложение работает в **локальном режиме** — без связки, данные только в localStorage. Это специально: удобно для разработки и превью дизайна без второго Telegram-аккаунта под рукой.

Внутри Telegram Mini App (когда доступен `Telegram.WebApp.initData`) включается **связка пары** — см. `backend/`.

## Запуск бэкенда (бот + API)
См. **`backend/README.md`** — там про токен бота, `.env`, как поднять локально.

```bash
cd backend
npm install
cp .env.example .env   # вписать BOT_TOKEN и BOT_USERNAME
npm run dev
```

## Стек
React 18 · Vite · Telegram WebApp API · Express · lowdb (JSON) · node-telegram-bot-api

## Структура
```
src/
  App.jsx              — оболочка, таб-навигация, состояние, синхронизация
  screens/             — экраны + модалки (настройки, редактор колеса, связка пары)
  components/Icons.jsx — SVG-иконки
  lib/
    storage.js         — локальное хранилище (localStorage)
    quotes.js          — цитаты дня
    palettes.js         — цветовые темы колеса
    api.js             — клиент backend API

backend/
  src/
    index.js           — точка входа (бот + сервер)
    bot.js              — /start, deep-link связка, ответы на приглашение
    server.js           — Express API
    db.js                — хранилище пар (lowdb)
    initData.js          — проверка подписи Telegram WebApp
```
