# Love App 💕

Telegram Mini App для пары — премиальный дизайн в стиле Apple.

## Экраны
- **Таймер** — счётчик дней/часов/минут вместе + цитата дня о любви. Настройки: дата, название, тема (тёмная/светлая).
- **Колесо** — рандомный выбор активности с анимацией. Редактируемые варианты + 4 цветовые палитры (Закат/Океан/Пастель/Неон).
- **Мечты** — список целей: добавить, отметить, переименовать, удалить.
- **Свидание** — позвать партнёршу с уведомлением в Telegram.

## Запуск
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # прод-сборка в dist/
```

## Стек
React 18 · Vite · Telegram WebApp API · localStorage (позже — бэкенд + бот для связки пары)

## Структура
- `src/App.jsx` — оболочка, таб-навигация, состояние, тема
- `src/screens/` — экраны + модалки (настройки, редактор колеса)
- `src/components/Icons.jsx` — SVG-иконки
- `src/lib/` — хранилище, цитаты, палитры
